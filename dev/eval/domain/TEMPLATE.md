# 领域评测集 v0 —— 题目模板（G2 关口）

**这份文件是格式 owner；真正填题的副本放 `dev/eval/domain/` 下的 `questions.local.md`（已被 .gitignore 排除，
不会进 Git）。** 填的时候复制本文件的「一条题目的样子」，凑到 **30–50 条**，然后：

```sh
pnpm eval:domain -- --file dev/eval/domain/questions.local.md
```

它会**逐题**跑一次真实 preset 会话（与 `pnpm eval` 同一套机制），把每题的**答案原文 + 机器观测**
（它查了哪些房间、加载了哪些技能、耗时）落成一份打分表 markdown；质量由你按下面的评分规则打分——
机器只守地板（"有没有查"、"有没有写文件"这类机械事实），**不判质量**（这是本仓的纪律：
`dev/eval/checks.mjs` 的头注写明"Quality stays a human read; the harness keeps the floor"）。

## 为什么这活只能你干

题目要**真实经营问题**：你自己会问、答案对不对你一眼知道、且答案依赖你公司盘里的真实数字。
编出来的题测不出"它到底能不能用"，只会测出"它会不会答题"。

## 一条题目的样子

```md
## Q1 · 这个月签单为什么慢

- 问法：这个月签单为什么慢？别给我泛泛而谈，给我能落地的判断。
- 期望：先给观察到的数字（来自公司盘），再给 2–3 条**可检验**的因果假设，并说清"要能定论还缺什么数据"。
- 该拒答：否
- 评分要点：① 引用的数字必须在公司盘里查得到（不能编）② 假设要能被一条数据推翻 ③ 明确说出还缺什么
```

字段说明（**只有「问法」是必填**，其余留空也能跑，只是打分表里少一栏对照）：

| 字段 | 填什么 | 空了会怎样 |
|---|---|---|
| `问法` | **你会怎么对它说这句话**——原话，别修饰 | 跑不了（唯一必填） |
| `期望` | 一次合格回答应该包含什么（一两条，别写成评分表） | 打分表里没这栏对照 |
| `该拒答` | `是` / `否`（`是` ＝ 超出它的知识或权限，正确行为是明说不知道并指路） | 按 `否` 处理 |
| `评分要点` | 你判分时会盯的点（1–3 条） | 打分表里没这栏对照 |

id 用 `## Q<数字> · <短标题>`；`·` 前后有空格；标题随便起，只为你自己认得出。

## 评分规则（打分表里每题都印一份）

| 维度 | 取值 | 判据 |
|---|---|---|
| **事实正确** | 0 / 1 / 2 | 2 ＝ 数字与结论都能在公司盘或记忆里查到；1 ＝ 大方向对但有不可核的数字；0 ＝ 编造或答非所问 |
| **依据在场** | 0 / 1 / 2 | 2 ＝ 明确指了出处（哪份原文/哪条记忆）；1 ＝ 提了来源但指不到具体；0 ＝ 没有依据 |
| **该拒答就拒答** | 是 / 否 / 不适用 | `该拒答：是` 的题里，它有没有明说不知道并指路；其余题填"不适用" |
| **可用性** | 0 / 1 / 2 | 2 ＝ 你据此就能动手（有下一步/负责人/判据）；1 ＝ 还要追问一轮；0 ＝ 用不上 |

**G2 通过的判据（先定死，免得事后争）**：30–50 题里——**事实正确 ≥1 的比例 ≥90%**、**0 分的题 ≤2 道**、
**`该拒答：是` 的题全部拒答**。达不到就把失败题攒成下一批切片（这正是评测集存在的意义：
它告诉你该修哪一块，而不是给产品打分）。

## 三条示例（**照格式抄，内容替换成你的**）

```md
## Q1 · 这个月签单为什么慢

- 问法：这个月签单为什么慢？别给我泛泛而谈，给我能落地的判断。
- 期望：先给观察到的数字（来自公司盘），再给 2–3 条可检验的因果假设，并说清还缺什么数据。
- 该拒答：否
- 评分要点：① 数字可核 ② 假设可被一条数据推翻 ③ 明确说出缺什么

## Q2 · 客户 Z 那单到底能不能破例

- 问法：客户 Z 非要 8.8 折，季末了，能不能破？
- 期望：把此前拍过的口径（不落价/不对外/不进退报价单）摆出来，说明这次为什么相同或不同，给一个可执行答复。
- 该拒答：否
- 评分要点：① 口径引对 ② 说清冲突在哪 ③ 给出对客户怎么说的一句话

## Q3 · 帮我估算明年的人力成本

- 问法：按我们现在的编制，明年人力成本大概多少？
- 期望：明说它没有编制表与薪资数据（除非公司盘里真有），指路该给哪份表；不许按行业均值编一个数。
- 该拒答：是
- 评分要点：① 明说数据不存在 ② 指路要哪份表 ③ 全程没有编造的数字
```
