用户要求先解决逻辑/自洽，再整理系统/结构；plans 推敲正确后才进入 proposed，reference 也要自洽。本 note 记录已交付的资料治理，不记录产品转向已完成，也不授权 UI/督办/审批/OV 实现、资产删除或外部递交。

综合转向稿曾提前进入 proposed，内部仍有审批语义、实验隔离/判读、状态契约、形态和资产审计未决。本轮移至 [转向自洽卡](../../_backlog/plans/261005-turnaround-coherence.md)，状态推敲中；未作整卡毕业、否决或拒绝用户已确认的方向。旧 [真用第一](../proposed/2026-10-01-real-use-first.md) 更新取代指针与历史边界，不把过去冻结或等待状态继续当现行调度。

## 已交付决定

1. **分层而非同步副本**：reference 拥有出处/反证/局限，plans 拥有消化/候选/毕业判断，proposed 拥有已成熟的具体问题/方案/验收。方向认可不证明效果，也不替所有切片完成毕业判断。定位、SDLC、首开与自洽卡各有 owner，索引反映实际状态。
2. **两轴证据判读**：规范决定与经验效果分开，schema/载体与实际路径分开；合成档、OKF 材料、演示脚本修正代理 trial 冒充 n=1、MUM→取消人报、premortem +30% 产品收益、负库存→永不仪表盘、官网→独占/真实用户等外推。原始 URL、原句和获取限制保留，未在本轮重新验证全部外部来源。
3. **窄研究而非继续铺资料**：一手代码核查形成 [技术审计](../../_backlog/reference/tech-exploration/261005-turnaround-evidence-audit.md)。当前审批是模型提示回退，Remote 审计有范围/失败边界；独立 DSH home 不隔离外部 OV；本地 storage 不证明推理留域。下一步只补真实决定/受众、可辨识实验与运行数据流；条件性补直接替代品或原统计，拿不到就收窄表述。
4. **制度入口按既有决定统一**：[notes 规则](../README.md) 的延后归属按 [治理决定](2026-10-02-backlog-governance-borrow.md) 区分未裁决/已裁决；已裁决触发住决定 note、卡关闭，不重建等待队列。暂停不算毕业；root/backlog 对 proposed 的绝对句收窄到重大未来工作，保留 notes 既有局部/机械编辑及轮内交付豁免。不改生命周期四态，不新增呈批层。
5. **现行合同只写已交付**：README 本轮只校准 owner 路由；产品方向合同迁移另作有界切片，不把候选督办/晨报/内联审批写现在时。已实现 note 的不存在 A/B 补记降未验、易过期数量改索引指针；未重写冻结归档。
6. **链接修复与覆盖补强**：搬主题子目录后相对路径修到真实 owner；上游放行/未递交状态一致，代理模拟不写成人类测试。[verify](../../scripts/verify.mjs) 保持原 markdownCorpus 的其他门范围，另将 backlog 根 README 与 plans/bugs/reference 的递归 Markdown 加入现有 relativeLinkProblems；[接线夹具](../../packages/dsh-smart-assistant/tests/verify-gates.spec.mjs) 用真实 runner 检出九个活跃位置的断链、修目标后转绿，并证明 `_done` 与未约定根材料不扩扫。纯核未改，未增加平行命令或产品行为。

本 note 部分校准 [backlog 治理](2026-10-02-backlog-governance-borrow.md) 与 [reference 分装](2026-10-05-reference-subdirs.md) 的绝对“唯一实施通道/内容不变”措辞：保留原生命周期与取证意图，澄清授权小修豁免及可解析链接修复，不另立规则体系。进度路由的细节见 [intents 退役补充](2026-10-04-intents-retired.md)。

## 输掉的方案

- **三层同步同一总计划**：重复状态、相互背书与授权不清，输给证据→推敲→单项毕业。
- **把综合稿留 proposed 等实现时再定**：把承重未决隐藏进实施，输给归位且保留已确认方向。
- **为了合拍删反证/扩大研究**：来源无法反驳、文章增加不补真实输入，输给适用边界与窄问题。
- **只修眼前断链**：现有检查语料遗漏会再次假绿，输给活跃语料接线与反例。
- **全面改产品合同、清理旧资产或冻结历史**：超出资料治理且易丢证据，输给按 owner、按成熟度、按范围的后续切片。
