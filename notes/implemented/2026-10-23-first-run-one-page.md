# 首开体验：一页纸（the one page）

## 问题（可观察行为）

2026-10-23 空 home 真机走查 + 一次真模型回合：启动落在仪表盘，空桌面上 14 个操作控件、0 条业务数据；
唯一解释「第一句话说什么」的 Day-0 卡因空判据不可达（[BUG-025](../../_backlog/_archive/fixed_bugs/BUG-025-first-run-day0-unreachable.md)）；
桌面与会话互相指路；人面没有能力菜单；首答 2055 字。目标用户是对 AI 不熟的高层：
零学习、零配置、一句话进入、五分钟拿到一页能读的东西。

## 决定

- **L0 一页纸**：主面板默认渲染一页当前事（账本 `matter.summary`，200–400 字，短行：判断 / 三条路各带代价 /
  建议 / 缺数 / 复查日）+ 一个输入；空态是它先问 + 3 个示例；页上三个动作（就这么办 / 改一改 / 先放着）走
  capture 车道；待审草稿、错误与风险永在 L0。「全部」进人读列表（每件事一行，点行选中回页），
  「完整看板」再进原 `projection-panel`；「看依据」就地展开 `matter.evidence`；对话是编辑层，不是家。
- **页的载体不新增 schema**：L0 页 = 账本 `matter.summary`；完整备忘 = 已存在的 `type: decision-memo` 知识页。
  v3 `brief` 字段不做，除非页上按钮需要选项级写入。
- **三条车道分开**：`[桌面]` 是 desk capture（note-first，含糊先记再问）；`[首页]` 是一页纸（本轮第一条消息就
  产出页）；`[面板]` 是页上按钮（命令，不落成片段）。混用会让首页消息被 note 成片段并反问。
- **首答合同**：manual v19「Answer with a page, not a report」+ `management-breakdown`「Land it on the desk」：
  draft-first（一句输入先给带显式假设的草稿，不先问卷）、一回合最多一问一动、首答 ≤400 字、说人话（页/桌面，
  不叫台账）、承诺可承接。固定 5 题 eval 守长度 / 问句数 / 页写入 / 指针。
- **三层表达**：L0 常用（默认）/ L1 高级（看依据、全部、它记下的，人话）/ L2 调试（`#debug=1` 或
  localStorage，会话视图栏独立 tab，只读：投影 / revision / ledgerId / 选中项 / session / JSON / 复制诊断）。
  审批、错误、风险永在 L0；层是问题域，不是密度。三档密度收窄为「只影响全部看板与房间入口」，首页不随它变。

## 输掉的方案

- **A 桌面＝今天这一件（任务卡）**：仍是任务管理器；被一页纸收敛（页比卡更接近高层产物）。
- **B 会话优先**：vendor 的空白会话是开发者语言，聊天记录不是高层要的产物。
- **C 只修引导与文案**：两对象互指、能力菜单、首答密度都不动；本仓同类症状已复发三次。
- **把三档密度当分层**：密度不是问题域；新手与专家被混成一个滑杆。
- **自动发首条消息**：2026-10-07 真机已证伪（十分钟六个幽灵会话）；要它先开口用确定性界面。
- **CSS 隐藏调试面**：隐藏不是不在场；L2 用独立门。
- **复用 `[桌面]` 车道做首页输入**：live 抓到它 note + 反问，页永远不出现；必须独立 `[首页]` 车道。
- **新增 v3 `brief` 字段**：三案例走查证明 summary 够 v0；先付 schema 成本不划算。

## 后果与边界

- 首页不读三档；设置行改称「显示密度（只影响全部与房间入口）」。这是对
  [三档界面 note](2026-10-23-ui-modes-and-panel-surface.md) 的部分收窄，两篇互链。
- 「全部」是人读列表；旧的完整看板退到「完整看板」第二层，不再承担「全部」。
- L2 只是呈现层，不是权限边界；客户默认不见，dev/probe 用 `#debug=1`。
- 页上按钮 v0 走对话车道（点击 → 助手回合 → 回执）；直写 host 路由是后续切片。
- 账本 / 投影 / 工具契约未改；只改客户端渲染与模型可见手册 / 技能。
