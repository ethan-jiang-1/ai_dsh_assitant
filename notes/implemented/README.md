# implemented/ —— 当前权威

本目录是**当前**仍在约束决定的那一层：一篇 note 的价值，是让下一次改这个决定的人不必翻 git，也不必从代码反推理由。

- 进这里的是**取舍**，不是记录：被击败的做法、说不清在保护什么的约束、只能靠历史解释的理由。
- 一篇一个决定；同一个决定只有一个 owner。事实变了改原文，决定反转另写并互链，完整被取代则同 diff 删除。
- 这里的话必须是**现在时**：写下的句子一旦不再为真，就没有资格继续留在这里。
- 规则、形态与移动手续以 [`../README.md`](../README.md) 为准；本页只声明这个目录的立场。
