# 三层界面重排：一个家，深看归位，调试一个门

## 问题（可观察行为）

2026-10-24 真机审计（空 home + 真实 dev home）：三层在主面板内部成立，但离开主面板仍是旧 feature silos——
会话「桌面」tab 是第二个首页（同屏两个输入）且与主面板各一个 selection store；「自动化任务」是并列的第五个
顶层面；右栏四间房是并列 tab，首页「它记下的」在主面板是死门（没有右栏）；完整看板仍是旧操作台
（capture、＋交代、有问题、重新读取、主动建议、待认领长文）；待认领长文污染人读列表；设置把
Viki(调试) 交给「专家」密度而不是 debug flag；首开有两张面（home 一问 vs 会话「一把手桌面/账本投影/桌面全景」）。
详见审计报告的 surface×layer 矩阵。

## 决定

- **主面板是三层，会话只做编辑**：常用面（今天一页纸）/ 深看面（看依据、全部、它记下的、它在盯什么、完整看板）/
  调试面（flag）。会话只保留 对话/轨迹（flag 时加 开发调试）；**退役会话「桌面」「自动化任务」tab**，
  回到今天走主面板/左栏「今天」，不再渲染第二个 HomeSurface，也不再有第二个输入。
- **调试一个门**：`#debug=1` 或 localStorage 标志同时决定「开发调试」tab 与 Viki(调试) 房；Viki 不在
  房间 guide 的默认注册里，也不再由密度打开。设置与命令不再出现 Viki。
- **密度只影响完整看板**：UI 标签 紧凑/标准/完整（内部 simple/standard/expert 只是存储值）；设置标题
  「完整看板密度（只影响完整看板）」；首页、全部、它记下的、房间、调试都不随它变；命令不再按密度隐藏。
- **它记下的**：主面板内新增只读记录面（知识非归档 / 记忆非内部规则 / 技能）；不再调用会话右栏的
  `openBeside('knowledgeRoom')`，死门消失。知识/记忆的原始房间数据是 agent 材料，这页做面向本人的过滤，
  并在副标题明说「归档与内部规则不在这里」。
- **深看归位**：全部列表 = 8 行事项 + 「它在盯什么」只读日程段 + 待归户只报计数（折进完整看板「后台」details）；
  完整看板由 HomeSurface 挂载时是 deep 变体：标题「完整看板」、只留「回到今天」，去掉 capture / ＋交代 /
  有问题 / 重新读取 / 「让它替你盯」；待归户折进后台 details；tab 改「事项/流水」。
- **首开只有一张面**：home 一问；blank 会话卡改成一句指针「今天的事都在今天这一页 → 回到今天」；
  审批两处文案统一为「N 页知识草稿等你审批——批准后才会成为它的判断依据 / 去审批」。
- **命名收敛**：今天（主面板/左栏）/ 全部（人读列表）/ 完整看板 / 它记下的 / 自动化（平台任务）。
  产品面退役「桌面」「桌面全景」「你的桌面」「全部事项」「看板（tab）」。内部「桌面投影 / desk」作为服务名保留。
- **测试合同同 diff**：`mount-rooms` 改为 Viki 只随 debug flag；`first-mile` 改为一句指针；`entry` 证明
  退役的会话 tab 不再注册；`one-page-home` 证明 deep 看板无混层动作、列表无待归户长文、记录面可达；
  三个 web-face 场景重录（blank / eight 首页 / eight 全部列表）。

## 输掉的方案

- **保留会话「桌面」tab**：两个 HomeSurface、两个输入、两个 selection store；用户无法判断哪个是家。拒绝。
- **把三档当用户层级**（简洁/标准/专家；专家含 Viki）：合同说层是问题域，不是密度；调试面不是客户面。拒绝。
- **在「它记下的」直接渲染原始房间**：首次真机渲染 8 条全是 deprecated agent 元页面、记忆里是内部规则；
  对一把手是噪音。拒绝，改为过滤后的只读视图。
- **保留完整看板的 capture/主动建议**：完整看板是深看，不是第二个 intake；这些动作归 home。拒绝。
- **从人读列表删掉待归户后完全不提**：用户会以为账上只有 3 件；保留计数 + 后台入口。拒绝静默。

## 后果与边界

- 平台任务详情仍在 vendor 的「自动化任务」面板；深看只读「它在盯什么」，不复制详情。
- **会话内 view 的平台约束**：`conversation.view` 的 slot store 是独占的，同一 view 注册两次会让 client entry 激活失败；平台没有应用级 tab strip，会话外不做浮层或改 vendor 壳。原 [workbench-tabs](../archived/2026-10-21-workbench-tabs.md) 的这两条实测约束在此保留。
- 调试面：主面板在 flag 下也有「开发调试」入口（HomeSurface 的 debug 态，带「回到今天」）；会话的「开发调试」tab
  仍只在有内容的会话出现（平台 view bar 生命周期），不再是唯一入口。
- 列表搜索已做：客户端过滤标题/摘要，query 在视图 store 里、不持久化；**删除不作为产品动作**
  （账本保留历史，事项是办结/放弃而非删除；知识/记忆的删除在房间）。这是判断，不是遗漏。
- 左栏「插件 / 自动化任务」是 vendor 壳，插件只能折叠/指路，不能移除。
- 直接挂载 `ProjectionPanel`（测试/兼容）保留全量 dashboard；产品深看经 HomeSurface 的 deep 变体。
