# 培养面设计思路（设计 owner）

日期：2026-09-26 · 状态：**proposed（进行中：本卡是培养面的设计思路 owner——原则、架构与判据在此；编年记录与逐圈证据在[活动卡](2026-09-25-ceo-sidebar-ux.md)，上手入口在 [handoff](../research/2026-09-26-handoff-ceo-sidebar-cultivation.md)。随真实使用演进）**

## 一、它是什么、为谁、怎样算好

**一句话**：培养面＝让本人**看见助手此刻的判断**，并**在看见它的地方直接处置**的界面。

**为谁**：中小企业 CEO/VP 的数字分身（[意图清单](../intents.md) §〇 的 P1–P3、O1–O6）；
首位真人＝用户本人。立场＝辅助本人（对外内容由他过目，不代他出面）。

**判据**（怎样算好，按优先级）：

1. **打开三秒内知道"现在要我干什么"**——行动面，不是审计清单（真人首测原话："能看到一堆东西……
   我跑到这个桌面上，你让我到底要干什么呢"，§四·二十）；
2. **看见的每条判断都能就地处置**——四类对象闭环（记忆/知识页/技能/线索）+ 决定与行动；
3. **处置后眼前的面跟着变**——"改了却不重渲染，读起来就像没听见"；
4. **每个数字与事实可追溯**——出处可见；陈旧会自己说"我旧了"；不编造；
5. **真实使用里的别扭能变成下一片**——真人实测 → 会话日志 → 切片（这条回路已完整跑通一圈）。

## 二、设计原则（系统化；每条＝主张 + 理由/证据）

1. **在看见它的地方处置它**。不是让本人去对话里描述"第几条错了"，而是每一行都带动作：
   记忆「这条记错了」、知识页「批准/有问题/过时了」、技能「有问题/没用了」、
   线索「问进展/先放放/收了」、决定「回答/看选项」、行动「改这条/办完了/不办了」。
   理由：指哪打哪是养成成本的下限——本人只在"看见的那一条"上有判断力。
2. **一个事实一个家**（内容分工）。桌面＝行动面；知识室＝它懂什么；记忆室＝它记住了你什么
   （全量审计清单）。同一事实不在两处渲染（例：「最近记住的」从桌面移除，归记忆室）。
3. **先说"从这开始"**。桌面首栏＝引导卡（第一条决定升格为大字卡，其余折叠）。理由：等权重的行堆
   等于没有入口（判据 1 的来源）。**已知缺陷（2026-09-26 评审核实）**：取的是 `decisions[0]`，
   而契约没有排序/分类字段——真实数据里引导卡当前展示的正是**助手的家务问题**（"培养面接着做深，
   还是先停一停？"）；修法＝契约加 `kind`/`rank`，见[评审记录](../research/2026-09-26-adversarial-design-review.md) §3。
4. **信任线**。每条记忆/知识页带出处（`source`/`sources`）；桌面带新鲜度（`generatedAt` +
   "对话比桌面新"告警）；技能里写死"没有出处就不要编造引用"、"陈旧或编造的清单比没有更糟"。
5. **面板是控制器，不是只读展示**。动作以**普通消息**送回对话（`sendPrompt`），助手改记录并在
   同一轮刷新桌面文件，面板自动重读（订阅会话 store + 延迟重读）。
6. **会话绑定**。每个面读它**所在会话**的工作区（`sessionId` 由 session 作用域 seat 直接提供）；
   跨会话数据不冒充（`sourceSession` 守卫：不属于本会话的快照显示"正在读这个会话的桌面…"）；
   动作路由到所在会话（`sendSession`），不是"最新会话"。
7. **忙时有交代**。提示发出后全部动作按钮冻结 + 明说"回复出现在对话里，桌面在它刷新后自动跟上"。
   理由：真人连点 3 次的教训（判据 5 的第一个实例）。**已知缺陷（2026-09-26 评审核实）**：
   `busy` 在提示被受理时即清除（毫秒级），冻结窗口＝受理窗口而非工作窗口——摩擦未修；
   修法＝数据闸门（pending 时间戳 > `generatedAt` 才解冻）。
8. **面板与技能同 diff**。desk 文件字段契约由 [`desk-refresh` 技能](../../packages/dsh-smart-assistant/presets/assistant/skills/desk-refresh/SKILL.md)
   （模型面）与 [client 面板](../../packages/dsh-smart-assistant/src/client/index.ts) 共同拥有，改一处必须改另一处。
9. **技能发现不靠运气**。面板动作提示**点名技能**（"完成后加载 desk-refresh 技能，把桌面文件重写一遍。"）。
   理由：实测小模型冷发现不可靠（多次真跑里出现不加载技能而徒手做）；面板提示是零常驻成本的必走之路。
10. **表达先于底层**（用户 2026-09-25 拍板）。先把表达/UX 想透、看得见，再落底层实现
    （typert 集成等后置——"UX 体验出来了之后，咱们再把底下落实的东西给落实了"）。
11. **助手家务 vs 本人生意**（⏸ 待用户价值判断）。当前 decisions 里助手 upkeep 占多数——
    自指闭环在表达层重演；分组与首屏占位等本人拍板。

## 三、架构（怎么实现的）

| 层 | 现状 |
|---|---|
| 形态 | 三室 × 两形态：主区域整页（`sidebar.panellist` + `main`）与右侧栏 tab（kind 型页，两段注册）；会话页头「桌面」chip 开启 |
| 数据通道 | **desk 文件协议**：助手用文件工具维护会话工作区 `.desk/state.json`；面板经**清单内**的 `workspaceFiles` Remote 读——绕开"仓外插件开不了新 Remote 命名空间" |
| 客户端 | classic script（无 import/export）；slot 系统 `inject`+`register`；vendor 类型结构化镜像 |
| 模型面契约 | `desk-refresh` 技能：字段、填法、四类动作的回程、"给选项≠回答" |
| 证据面 | 面板渲染测试 `client-panels.spec.ts`；行为评测 `pnpm eval -- --only desk-refresh-loop`（skill-loaded + wrote-path + 报计数）；`preflight`（boot 图 / Remote 清单 / desk 段）；真人实测 |

机制细节（两段注册、session 作用域 seat、恢复态语义、boot 图）的 how-to 权威是开发技能
[`client-ui-contribution`](../../.agents/skills/client-ui-contribution/SKILL.md)；typert 阻塞的完整证据链在
[活动卡 §四·二](2026-09-25-ceo-sidebar-ux.md)。

## 四、现状盘点（2026-09-26）

**已交付**：三室面板、右侧栏 tab、会话绑定读取与动作路由、四类对象就地循环、决定可就地回答、
行动在办/已办分组、「先办这件」引导卡（**评审核实：取下标非优先级，当前展示助手家务，待修**）、
忙时冻结（**评审核实：窗口错误，待修**）、信任线（出处 + 新鲜度）、preflight 关口、
行为评测网、真人首测全链走通。

**对抗性评审的修复包（2026-09-26，⏸ 待用户拍板）**：[评审记录](../research/2026-09-26-adversarial-design-review.md)——
判决"这是工作目录的只读投影 + 模板消息发送器"；修复顺序＝内容政策（`kind`/`rank`）→ 协议回执
（`options[]`/`pending`/`reply`/`note` + 数据闸门）→ 窄栏密度（一行一条/层级/按钮对比/暗色 token）；
另含 A1–A10 十条代码级缺陷（技能行发错对象类型、陈旧告警失准、跨会话静默回退、固定重读窗口等）。

## 五、输掉的方案

- **自建 Remote 命名空间**（`TypertRemoteService`）：仓外插件进不了构建期清单，客户端永远等不到——
  整段回退；替代＝desk 文件协议。证据链留[活动卡 §四·二](2026-09-25-ceo-sidebar-ux.md)。
- **装第三方 sidebar 包**：只借思路不装包（第七条硬规则）。
- **全功能仪表盘**：CEO 不要 BI 工具，要的是"助手状态一览 + 指哪打哪"。
- **先做 genui 式回复内渲染**：依赖最重、链路最长，放最后。
- **面板留在主区域整页**：用户 2026-09-26 拍板右侧栏 tab（body 直接拿 sessionId、紧挨对话）。
