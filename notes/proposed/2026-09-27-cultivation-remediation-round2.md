# 培养面二轮整改：自主两轴评审的发现 → 有序列切片（R1–R10）

日期：2026-09-27 · 状态：**proposed**（用户 2026-09-27 拍板"自主评审、别动不动让人 review"后的首个自主评审产出；切片按严重度排序，逐片落地）

## 问题（怎么来的、证据边界）

按[研发姿态](../../AGENTS.md)自主跑了两轴评审（两个子代理并行，互不污染上下文）：

- **对抗性设计评审**：读实现（`src/client/index.ts`）、desk 契约（`presets/assistant/skills/desk-refresh/SKILL.md`）、
  真实 `.desk/state.json` 与四组真机截图/DOM 证据，逐条给 `file:line`。
- **可用性走查**：以"第一次来的 CEO"视角走四条判据（三秒知道干什么／就地处置／三室＝三问／可追溯），
  并量三处最高摩擦。

两份独立、结论高度一致（一致处＝高置信）。**发现全部经开发者复核**（我逐条对着代码与 DOM 数字看过）。
证据面：[截图目录](../research/2026-09-26-first-mile-shots/)（含 `.dom.json`）；上一轮整改的
[已交付卡](../implemented/2026-09-26-cultivation-remediation.md)是这些面的第一轮。

## 切片（按严重度；每片一个垂直切片，独立提交）

### R1 冻结永不过期，且把逃生门自己关掉（两轴一致，最严重）

`frozen = pendingInFlight(store)` 是**面级**的：动作发出后 `pending` 一直留着直到 desk 文件被重写；
轮询 15×10s 放弃时**不清 pending**，而 `刷新桌面` 自己 `disabled: inFlight` ——一次没被重写的回合就把
三室所有按钮永久冻死（不透明度 .5），解释只在被动过的那一行。真机数据支持"很常见"：
`p2b` 桌面 23:14 vs 对话 01:48，`p1a-clickthrough` 桌面 23:14 vs 对话 12:00（13 小时后仍冻）。
**修法**：① 轮询放弃即清 `pending` 并落一句诚实的话（"它还没重写桌面——点「刷新桌面」再试"）；
② `刷新桌面` **永不** disabled；③ 冻结的说明从"正在处理"变成带超时的状态。
**验收**：夹具（轮询耗尽 → 按钮解冻 + 提示在场）；真机复现一次（发一个动作 → 等到超时 → 看按钮回来）。

### R2 「看选项」把决定自己吃掉（对抗评审，高）

`answered = pending.rowId===id || lastReceipt.rowId===id` → 行进 `readOnly`：控件消失、打印
"已回答——改主意？…"、`options` 也一起隐藏。而"看选项"这个动作本身会让文件移动 → 结算 → `lastReceipt`
落下 → **用户要的选项到此消失，行也死了**（刷新才回来）；且"已回答"是假话（他并没回答）。
**修法**：`readOnly` 只由**回答**触发（不为"看选项/问进展"这类读取动作落 receipt）；
活着的决定永远渲染 `options`。**验收**：夹具（看选项后行仍可答、选项仍在）。

### R3 「办完了」是正向动作，不该二次确认（可用性走查，中高）

`办完了/不办了` 都带 `destructive: true` → 首次点击变"确认办完了？（可恢复）"、3 秒窗口、`h=18` 的
小按钮。完成一件事不需要防误触；"不办了"（撤下）需要。**修法**：`办完了` 去掉 `destructive`，
`不办了` 保留；确认窗口从 3s 放宽到 5s（小按钮 + 中文输入法的现实）。
**验收**：夹具（办完了单击即发；不办了仍需二次）。

### R4 首办卡的分类规则漏了"只有你能办"的那类（对抗评审，高）

真实文件里三条决定 `kind: upkeep` → 引导卡显示"目前没有需要你拍板的经营事项"，而折叠里躺着
"知识室两张 draft……只有你能把草案变定稿"（还带 2 个一键选项）。
**修法**：契约加一条规则（写进 SKILL.md）——**带 `options[]`、或属于"等你审批/只有你能办"的决定，
无论 `kind` 都进引导卡**；客户端的取卡条件同步放宽（business 优先，其次"有选项的 upkeep"，最多一条）。
**验收**：SKILL.md 规则 + 客户端夹具（只有带选项的 upkeep 时 → 上卡）+ `pnpm eval -- --only desk-refresh-loop`。

### R5 「缺什么」只说要人给，却不给处置入口（两轴一致，中高）

缺口行（"「20%」的原始读数""9 家客户的合同台账"）**没有任何控件**，desk 自己写着"想补只需回一句"，
即回到对话——违反判据②（看见的每条判断都能就地处置）。
**修法**：缺口行用 `CorrectableRow`，动作「补上」→ `[桌面] 缺口的原始读数：<text>…`（带缺口标题）。
**验收**：夹具（缺口行有「补上」且消息点名缺口）+ SKILL.md 回程说明。

### R6 右栏 tab 读失败 = 永远的"正在读…"（对抗评审，中）

`loadDeskFor` 的 catch 只 `patchDesk({note})`，而 tab body 在 Panel 之前就返回 → note 不渲染，
重试按钮只在 `readError`/`misses` 分支存在。**修法**：catch 落 `readError`（与主面板同一条出路）。
**验收**：夹具（读抛错 → tab 显示错误 + 重试）。

### R7 密度与内容资格（两轴一致，中）

实测：`threads[0].lean` 单块 **h=345（占窄栏 35%）**、`它记` 是模型的自纠日志（11px 橙、最高 53px）、
Markdown 原样直出（DOM 里能看到 `**已消解**`）、`来源` 只截 110 字符（真实页 11 条/945 字符 → 可见约 12%）、
计数行（记忆 7/知识 13/技能 12）自己没有出处与时间。
**修法**：① 自由文本字段（`lean`/`why`/`它记`）加**长度钳制 + 展开**（不是删，是收）；
② 极简 Markdown（粗体/行内代码）渲染成元素，不留星号；③ 出处给"看全部"的展开位（不靠 hover）；
④ 计数行带上自己的 `generatedAt` 与作用域。
**验收**：夹具（长字段截断 + 可展开；`**x**` 渲染为 `<strong>`；出处展开）+ 截图前后对比。

### R8 尺寸与对比度不达 AA（对抗评审，中；视觉类须截图复核）

按钮 `h=18` / 11px 文本（低于 WCAG 2.2 的 24px 目标）；`#0d9488` 3.74:1、`#aaa` 2.32:1、
`#bbb` 1.92:1 均在 AA 之下。**修法**：动作按钮 ≥24px 高、正文对比度提到 ≥4.5:1（暗色主题另算）；
改完**必须出截图对比**（S5 方法纪律）。**验收**：截图对比 + 门禁绿。

### R9 静默无操作与缺失状态（对抗评审，中）

① 页头「桌面」chip 与 `/desk` 失败只 patch `note`（渲染在面板体内）→ 失败不可见；
② `cell()` 吞 `selectPanel` 的 throw → 有下划线、有 pointer 的数字点了没反应；
③ 计数/跳转是 `onClick` 的 div，无 role/tabIndex（纯鼠标）；④ `threads[].status` 声明了却从不
过滤或显示（parked/closed 的线索照样回「在跟的事」）；⑤ 除 done/dropped 外的一切 action status
都算"在办"（拼错的状态会显示成在飞）；⑥ dropped 的行动哪里都不渲染（真实文件有 2 条）→
「不办了」没有可核对的留痕。
**修法**：① 失败落一个面板外的可见回执；②③ 用真 `<button>` + 失败不吞；④⑤⑥ 状态收敛成
明确集合 + 已办/已撤两组各自可见。**验收**：夹具（未知 status 落到诚实分组；dropped 可见）。

### R10 引导条把 CEO 送进开发者的门（两轴一致，中）

引导条写"· 敲 / 看它现在能做什么"，而 `/` 菜单的顺序是 Add(File/Feedback) → Commands(Compact/
Permission/Model/Export) → 我们的三室 → **15 条英文技能**（`client-ui-contribution`、`repo-live-probe`
这类开发技能也在列）——正是 `index.ts` 自己在知识室里排除的"委托人面上的噪声"。
**修法**：① 引导条删掉"敲 /"这半句（改成指向三室与桌面）；② 技能进不进命令菜单是**发行/准入**问题
（不是客户端能改的），记为发行清单一条：产品组合应只带产品技能，开发/仓库技能不进委托人面。
**验收**：截图（新文案）+ 发行清单一条。

## 输掉的方案

- **"先做视觉大改（R8）"**：视觉类改动没有前后截图不许下结论（S5 方法纪律），且 R1/R2/R4 的面级
  正确性优先——先让面不再骗人，再让它好看。
- **"把 `它记` 直接删掉"**：它是信任线（助手自纠的记录），删了就看不出"它改过口径"。R7 取"钳制 + 展开"。
- **"冻结改成 promise 闸门"**：S2 已经用数据闸门取代过 promise 闸门（受理≠完成），本片只补**过期**，
  方向不变。
- **"技能菜单问题由客户端隐藏"**：客户端看不到别的插件的命令来源，也没有隐藏它的公开面；
  硬做等于猜。归发行/准入。
