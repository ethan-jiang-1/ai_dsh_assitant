# archived/ —— 冻结的历史

本目录保存**已经交出决定权**的 note：它们曾经是某种取舍的 owner，现在只回答「当时怎么想、最后为什么没走」。

- 冻结是这里的唯一规则：不更新、不修正、不追加（唯一例外：链接失修——入链或出链）；内容后来变错，由拥有它的新 note 负责，历史不为今天让路。
- 只有整篇不再指导下次改动时才进来；仍指导下次改动的留在 `implemented/`。只是被新 owner 引用为历史出处、而现行测试/门禁/owner 不再以它作理由的，可以归档。
- 它的价值是**可读、可引用、可追溯**，不是当前权威；引用它的人要明白这是过去时。
- 规则以 [`../README.md`](../README.md) 为准；本页只声明这个目录的立场。
