## 方案与取舍

三片、一次工期，**模型可见面零变化**（不动 persona、工具、摘要口径）：

| 片 | 做什么 | 定案要点 |
|---|---|---|
| **A1 读权威** | 宿主加 `assistantRooms` 只读路由（形状照经营投影），客户端面板改读它；`.desk/state.json` 与 `desk-refresh` 技能退役 | 面板由 store 按**数据变**渲染，不按轮数；空控制台契约不变 |
| **A2 直写** | 扩 `approvePage` 那条车道：记忆纠错/退役、知识批准/过时、技能退役 | **只翻状态 + 改一句记忆文本**（Q2 定案）；**不新增**（Q1 定案，交给 C 卡的"记下来"）；每次带 `source: panel-direct` 入审批账 |
| **A3 收据** | "自上次以来变了什么"：文件 mtime + `audit/approvals.jsonl` 的纯核 | 不新增任何 `SessionEvent`；替代"刷新"这个动词 |

**冲突与退役的形状定案**（本人 10-19 交 agent 判，三段判据的完整论证 = 依据档 §5.3）：

- **取代**（同一事实新值进来）→ 机器标 `superseded` + 指针，**不删文件**：旧值曾经真过，审计链要留。
- **冲突**（两条矛盾、没有权威谁新谁对）→ 机器**不代删**，并排摆出来 + 一句"以哪条为准"；人点完才变成取代并丢弃另一条。谁新谁对由人判，不由机器猜。
- **退役**（人判"不该再被用"，如别家公司、口径不对）→ 真的删除，但**先备份**（房间 `archive/`、Viki snapshot）且**引用证明**（`supersedes`/`supersededBy`/知识 `sources`/线索指针都不指向它）。

已输掉的做法（外部证据 + 本仓判据，逐条在依据档 §5.1）：自由 Markdown 编辑器、面板直调模型 API、每写先排队等人批（候选层）、自动轮询拷贝、统一存储、为面板先建派生索引。

## 验收标准

| # | 判据 | 断言目标 |

| 1 | 面板数据源是房间真值 | `src/` 内对 `.desk/state.json` 的读写**零命中**；面板数据由宿主路由供给；`desk-refresh` 技能删除、`docs/home.md` 家手册节与 `_backlog/triggers.md` 对应行同 diff 退役 |
