# 推敲：学到的东西——技能逐件可见与"记下来"（C 卡：P2/P3）

> 立卡：2026-10-19 ｜ 状态：等人拍板 ｜ 类型：Feature ｜ 可关闭：否 ｜ 毕业：做现在（P2 先做，P3 待确认）｜ 下一步 = 本人确认 Q2（P3 是否同卡做）

> **依赖：** A 卡的直写车道（C1 复用）；依据档 [self-update/261019-self-update-lanes](../research/self-update/261019-self-update-lanes.md) §一（技能两写入口）、§三 D5。

**问题与期望结果：** 产品判据 P3 要求"学到了什么，用户能看、能改、能删"（[README](../../README.md)），而技能是三处来源里**最看不见**的一处：面板只有一个计数，正文要开文件，退役只能靠对话；直写 `save_skill` 无门、用量账本只有 curate 会读。同时"我想让它记住这句"今天只能靠一句含糊的"记一下"。要的是：**逐件看到技能（名字/用量/最近使用/出处/正文）+ 一键退役**；以及**在消息上直接说"这条留着"**，一次确认就进记忆。
**当前情况：** 技能两写入口（`save_skill` 直写 / `propose_skill` → 人改 approved → `land_skill`）与用量账本 `skill-usage.json` 都在，缺的只是面；消息级动作槽 `conversation.chat.assistant-actions` 在 vendor 里是**既有 slot**（`list`，每格收到 durable message id，不改它就是"标准动作行不变"）——P3 不需要发明交互槽。
**下一步：** 本人确认 Q2 后，C1 与 C2 同卡两片并行（都只动 client + 宿主只读/直写，无模型可见面新增）。

## 方案与取舍

| 片 | 做什么 | 要点 |
|---|---|---|
| **C1 技能面** | 学到技能逐件列表：名字 / **context 成本** / **调用次数** / 最近使用 / 出处（`metadata.origin`）/ 状态；点开只读抽屉看全文；一个"退役" | 列的形状照 **Claude Code `/skill-doctor`（≥2.1.252）的 `/plugin` Stats 页**——第一方唯一先例，列的就是"成本 + 次数 + 关在哪"；复用 A2 的直写车道与审批账（`source: panel-direct`）；退役=移到 `archive/`，模型目录与摘要同时消失 |
| **C2 "记下来"** | 消息动作"记下来"：取该条消息（或选中片段）→ 生成记忆（active，`source: panel:message:<id>`，带 `why`）→ 面板收据显示 | 走 A2 同一条写车道；不做候选态（§四 结论 1） |

**做法取舍：**

- **不做技能"新建"表单**：新技能必须由模型写过一次（`save_skill` 有引用完整性检查），人填表等于绕过检查。
- **不做技能用量排行/图表**：P3 只要求看得出"学到什么、用没用、能不能删"；两个数（成本、次数）+ 一个关闭口就是外部先例的全部形状，排行是装饰。
- **不在 UI 里区分"自学"与"作者写"**：外部无先例（Claude Code 的 Stats 不分来源），本仓也一样用 `metadata.origin` 标出处即可，不另做分栏。
- **不做"记下来"进候选队列**：一次确认即入库，撤销靠 A2 的退役（外部同形：Claude Code `/remember`、Letta `/remember` 都是直接写）。

## 验收标准

| # | 判据 | 断言目标 |
|---|---|---|
| 1 | 列表 = 学到技能真值 | 3 件 fixture → 3 行；每行有名字/用量/最近/出处；不可调用技能不出现（`isModelInvocable` 过滤） |
| 2 | 退役生效且可回滚 | 退役后模型目录、摘要计数、技能列表三处同时消失；`archive/` 里有原件（spec 断言三处 + 文件存在） |
| 3 | 退役留痕 | 审批账追加 `source: panel-direct` + 技能名 + 前后状态 |
| 4 | 正文只读抽屉 | 点开 = `SKILL.md` 全文（与磁盘逐字一致，spec 用 hash 比对） |
| 5 | "记下来"生成一条记忆 | 点击后 `memory/` 新增一条，`source: panel:message:<id>`、`why` 非空、摘要下一轮可见 |
| 6 | 动作槽不改标准行 | 未点击时消息动作行与出厂一致（组件 spec 断言既有动作 id 集合不变） |
| 7 | 零模型回合 | 列表/退役/记下来都是宿主路由或直写，探针断言无会话、无模型回合 |
| 8 | 收尾 | `pnpm typecheck && pnpm test && pnpm verify` 绿；动 client 先 `pnpm build` + `pnpm shots` |

## 关闭条件

C1（必做）与 C2（按 Q2 决定）落地且上表有真证据；技能在面板上"能看能退"，"记下来"一次确认即生效；结论与去向按[关闭条件](../README.md#关闭条件)交接后归档。
