## 卡片模板

```markdown
# BUG-<NNN>：<一句话标题>

> 严重级别：P0（阻断）/ P1（重要）/ P2（次要）｜发现：YYYY-MM-DD｜状态：活跃

## 症状
观察到什么错误行为（现场、报错、复现路径）。

## 根因（假设）
机制层原因——越到契约/结构层越好，避免只描述表象；未定位就写假设与验证途径。

## 复现
最小复现步骤 / 命令 / 输入。

## 修复关联
落地方式（修复 commit / 搁置池行 / 症状签名入档的 note），修完归档时补。
```

**边界**：当场修掉的缺陷不建档（轮内收尾记录照旧）；建档 = 发现时决定不当场修。
已有归宿的旧缺陷不迁移。
