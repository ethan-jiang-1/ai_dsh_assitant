# BUG-019：主动行的动作在「流水」下是 no-op，「去处理」也不滚动

> 严重级别：P1（重要）｜发现：2026-10-19｜状态：修复就绪

## 症状

- 看板模式点「去处理」：`showList` 只设 `pane='list'`，桌面本来就在列表，画面完全不变（点击前后 scrollTop=0、截图一致），而"2 条待认领"在 1600×1000 首屏下沿之外。
- 流水模式点「看这件事」：`selectMatter` 设了选中和 `pane`，但 `mode` 仍是 `activity`，详情面板不渲染——什么也没发生。

## 根因（假设）

已确认：两个动作都只改 view store 的局部字段（`src/client/projection-view.ts` 的 `showList`/`selectMatter`），不切换 `mode`、不滚动/聚焦目标；主动行渲染在 tabs 之上，两种模式都可见。

## 复现

dev 桌面点行 2 的「去处理」比对前后截图；切「流水」再点行 1 的「看这件事」。

## 修复关联

动作应显式给出结果：`setMode('board')` + 选中目标（去处理可选中第一条待认领或滚动到待认领区）；同 diff 改组件判据。

## 修好定义

从流水点「看这件事」切回看板并选中该事项；看板点「去处理」把待认领区带进视口（或选中第一条）；两条组件判据 + 一张真机前后帧。
