# 技术定调：OKF/WIKI 的能力边界与可辨识实验

> 立档：2026-10-05 ｜ 喂 [定位卡](../../_done/_closed_plans/261005-open-value-deficit.md) 与 [自洽卡](../../_done/_closed_plans/261005-turnaround-coherence.md)。
> 用户选定探索方向：有组织的知识、技能和事件信息能帮一把手什么；OKF/VK 与 DSH 原生优先已确认。选择方向不是测得收益，本档区分 schema 能力、当前实现与效果假设。

## 一、两类记忆与当前资产

- OV 的情景记忆面承载会话经历/召回；[层 1 决定](../../../notes/archived/2026-10-04-openviking-layer1-landing.md) 记录安装、组合和有限跨会话证据，不是管理价值对照结果。
- OKF 子集的语义知识页承载口径、来源与生命周期；memory/knowledge/skills/research 是现有布局，不等于“突发事件管理系统”已实现，也不等于公司决定对象/状态机已完备。
- 底层字段来自既有知识页 schema；实际审批/审计/OV 隔离的源码事实归 [技术审计](261005-turnaround-evidence-audit.md)，本档不维护第二份代码台账。

## 二、字段 affordance 与未成立的承诺

| 字段/机制 | 可指认的结构能力 | 不能仅据此承诺 |
|---|---|---|
| `sources` | 页可以存来源定位 | 每个数必有正确来源、召回一定带出处 |
| `status: draft/stable/deprecated` | 生命周期和检索边界、旧页可保留 | 错口径能自动撤销、所有执行者拒绝旧版 |
| `stale_after` | 到期可以纯比较/报告 | 模型必然按新口径判断、通知已投递 |
| `generated / verified` | schema 可表达生成与验证的区别 | 当前 promote 会写 verified 或本人审核已被可信绑定；实际 promote 只翻 status |
| `[[互链]]` | 口径关系可显式表达，见 [curate 决定](../../../notes/implemented/2026-09-24-knowledge-curation.md) | 链接必定被召回、分歧/因果正确 |
| `type` | 容忍未知类型、不设中央注册 | 完整业务对象、状态 owner、事件转换已经定义 |

普通文件/聊天也可以承载来源和判断材料；本假设是结构与生命周期能让查询/撤销/归因更可靠，不是它们在别处“不可能做到”。留痕可以审计过程，不等于判断正确；结果验证仍依赖事实、预期与后续回访。

## 三、设计假设与反证

候选映射：决定引用来源页、保留分歧、记录可证伪信号、暴露缺数与过期。每个映射都必须指认消费路径，不能从字段存在跳到收益。

[替代品格局](../positioning/261005-substitute-landscape.md) 只提供有限范围的公开能力/叙事比较；不能证明平台没有公司对象或本方案独占，竞品已有检索/治理能力是对照与反证。

## 四、实验问题分两层（尚未执行）

1. **可用性四格**：相同任务下，公司知识有/无 × OV 开/关的增量是什么？主要测额外知识内容与情景记忆，不独立归因 OKF 组织结构。
2. **等内容结构消融**：同事实、同文本/来源的平铺 Markdown vs OKF 页/生命周期/互链，比较来源定位、撤销旧口径、过期、冲突与缺数。尽量固定模型、题目、评分、检索/召回量与 token 预算；控制不了的差异报告为混合干预。

先跑 8–12 个仪器病例/配对组证明隔离、抽取 readiness、证据采集和评分一致，再决定正式规模。既有 40 题是用户提供领域题集，但含自指题、并非全部真实经营案例；按独立事实/拒答/判断/跨会话组分层，不把30/30机器预评分当真人评审。

现有 `eval:domain`/preset-runner 不是隔离四臂执行器。home 之外还需 OV server/store/account/peer/actor 与 legacy/降级负测、全房间/桌面/提案/会话索引基线；独立题重置，配对组仅组内保留指定学习，等待实际 commit/flush 完成。金标准对模型不可见，按组/重复独立取样，不能把同组追问数当独立样本。固定等待和随机臂顺序不能替代隔离；详见 [技术审计](261005-turnaround-evidence-audit.md)。

本仓四格/A-B 正式对照尚无结果；不把未跑实验叫验证器已建。仪器实施提案凭可测试隔离设计、manifest、评分/验收、成本与停止规则成熟后毕业；正式批次才依赖隔离器实际运行验收。二者分开，不要求先实现仪器再授权实现它。

## 五、判读与失败定位

指标候选：来源归因正确率、冲突/旧口径误用、正确拒答、跨会话召回、任务完成质量、延迟/token成本。明确金标准、分母、误差/重复与盲评；零冲突是目标，不是先验必须出现的结果。

失败先区分：语料缺事实、事实存在但召回失败、写入/抽取未完成、生命周期消费错误、身份/审计/权限错误、评分题与样本问题。未审批不自动推出“应内联审批”，也可能是输入质量、必要性或噪声。

以下只是可证伪假设：知识有助有事实依赖任务；OV 有助指定跨会话记忆；拆解题可能作为低依赖对照，但也可能受内容/上下文影响。无知识时正确拒答应仍成立，“拒答塌方”不是期待。增益/无增益不自动定位为“种子太薄/全部归因价值”，先检查控制、泄漏与测量。

## 六、边界

单人当前场景不夸多人下发/上行能力；技术方向已选不等于每层必须证明正收益。治理/可回溯性的价值与回答得分分别报告，不能只看一个总分。知识种子厚度要由真实缺口决定，不靠增加内容换取实验胜利。产品/演示价值另需真实决定与受众，不能让技术对照替代。
