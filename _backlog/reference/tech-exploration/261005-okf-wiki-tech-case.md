## 一、它管哪种记忆（认识论定位）

认知的二分正好映射两件已建资产：

- **情景记忆**（哪天谁说了什么、上次说到哪）→ OpenViking 层 1（已落地，见
  [landing note](../../notes/implemented/2026-10-04-openviking-layer1-landing.md)）；
- **语义记忆**（口径、制度、数字、决定——"公司的事实底账"）→ **OKF/WIKI 知识页**
  （六字段子集 + [[互链]] + curate）。

「管知识、管技能、管突发事件」三类恰好对应 knowledge / skills / research 三房间 + OV——
"有组织的信息系统"不是比喻，是布局本身。

## 二、OKF 六字段子集：每一格都是给一把手的具体好处

| 字段 | 给一把手的好处 | 纯聊天记忆为什么做不到 |
|---|---|---|
| `sources` | 「这个数从哪来的」永远答得出（O1 出处） | 聊天上下文没有出处字段 |
| `status: draft→stable→deprecated` | 口径错了**可撤销**，旧版留底、链接不断（OKF §5.4） | 上下文越聊越脏，改口=覆盖 |
| `stale_after` | 过期是**机器可查**的（curate 一次纯比较，OKF §5.5） | 模型对"这条是去年的"没感知 |
| `generated / verified` | AI 起草 ≠ 本人确认，**分离且留痕**（OKF §5.2/5.3） | 聊天里谁是源头说不清 |
| `[[互链]]` | 定价口径连着毛利底线连着审批线——口径成网 | 每句话都是孤岛 |
| `type`（不中央注册） | 消费者容忍未知类型——知识可以先长后分类（OKF §4.1） | 预定义 schema 挡住生长 |

## 三、为什么它是「判断工作」的承重技术（第 11 轮定调的技术面）

一把手的工作是复杂域的活：没有标准答案、高不确定性、信息分布在外部、产出是判断与决定
（非黑白）。五条设计公理的技术落点全部压在这层：

1. 工作单元 = **决定** → 决策卡引用口径页（`sources` 指到"你 10-04 批的那页"）；
2. **不合并分歧** → 口径可撤销、旧版留底（`status` 生命周期）——分歧有处安放；
3. 不确定性 → **可证伪化** → 假设页带 stale_after，"能杀它的数"到期机器可查；
4. 信息分布复杂 → **缺口是一等对象** → 知识页"未写成"只报 info（OKF："may simply represent
   not-yet-written knowledge"——成长中的知识不算病，[断链三档](../../notes/implemented/2026-09-24-knowledge-curation.md)）；
5. 判断不可验证 → **留痕即验证** → generated/verified 分离 + sources——判断工作的"测试"
   就是因果链可回溯。

**替代品格局的佐证**（[substitute-landscape](261005-substitute-landscape.md)）：平台记忆只有
"关于你的摘要"，无"公司作为一等实体"（决定/行动项状态机）——OKF 知识层 + 决策卡正是这个
实体的技术形态。平台卷能力，我们卷**工作形状的贴合与信任架构**。

## 四、"有了问题好修整"：2×2 实验与失败归因（提升机制）

**实验**（用已有资产，不建新台子）：知识室满/空 × OV 挂/不挂，四格各跑 40 题真实域评测
（`pnpm eval:domain`；题面不动；dev-ov/dev-task 双 profile 先例在）。诚实记账：OV note 验收表
承诺的「A/B 两臂补记」尚未落数——本轮顺手补。

**判读指标**：①引用归因率 ②口径冲突数（应恒 0）③拒答正确性 ④跨会话追问组 ⑤拆解题分
= 阴性对照（预计无差）。

**失败按层归因**（每道失分题归四类，各对应一个技术杠杆）：

| 失败类 | 修哪里 |
|---|---|
| 缺页（该有的知识没写） | 种子/导入管线 |
| 页在没召回 | 检索排序/摘要预算 |
| 情景没写入 | OV commitTokenThreshold（3000 待真实使用校准） |
| 写了没审（draft 积压） | 审批内联化 |

**提升由评测分+归因分布驱动，不由"能否自造自验"驱动**——防自指闭环（grand plan §1.3）的
关键机制，也是"技术不断往上提升"的路径本身。

**可证伪预言**：知识层对口径/数字/制度题显著提升、对拆解题≈0；OV 对跨会话组决定性、对
独立题≈0；拒答题在知识室空时塌方。任一意外都指向明确的修哪里（知识层连拆解题都提升 =
种子太薄；拒答没塌 = 知识层价值全在归因）。

## 五、诚实边界

- **乘数不是加数**：拆解题不涨分；"帮多少"取决于问什么——实验先行，不做能力承诺。
- **单人场景用不上多人治理**：组织层下发/上行（grand plan §2.5 的 O5/O6 面）是未来价值，
  现在不吹。
- **种子内容薄**：管理岗知识 7 页——Peel Back 段的说服力与实验读数都会暴露"哪页该厚"，
  这正是实验的副产品。
- 事实层的硬对错不与判断层的无对错混淆（O1/O3 承重）。
