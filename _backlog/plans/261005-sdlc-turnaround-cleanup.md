# 推敲：定位翻盘后的 SDLC 重修与 harness 打扫

> 立卡：2026-10-05 ｜ 状态：推敲中｜毕业门判断 = 待定（资料层核查已获授权，产品资产处置仍缺证据）｜下一步 = 先按 [自洽卡](261005-turnaround-coherence.md) 对齐资料生命周期与边界；实际资产/门禁退役另作有界提案

本轮授权范围是资料逻辑、自洽和结构：可以核查来源、修断链/状态、归位未成熟综合稿；不扩大为产品机制、门禁、运行数据的清扫授权。以下三问是资产审计候选判据，不是已做完的处置表。

## 背景 / 触发

用户 2026-10-05 原话："DSH SDLC 流程这里，可以见我们现在有一点点翻盘的样子；历史上可能
做了有些东西是完全没有意义的，要丢弃；harness 一定要打扫干净；这种 SDLC 也需要探索出来。"

触发源：[261005-open-value-deficit](261005-open-value-deficit.md) 十九轮定位翻盘——从"通用
自用助手"到「一把手的总助：你拍板，它盯到闭环」+ 双重目的（真用/打动管理层）+ 判断工作
定调 + AI 擅长三区过滤器。**北极星换了，开发流程（SDLC）还长在旧北极星上**——这正是总体
思路 §1.3 记档过的结构病：流程是 agent 能自造自验的东西，会自然朝旧判据漂移。

## 已知与未决

### 已知

1. **翻盘清单（什么变了 → 流程必须跟着变的点）**：受众（开发者→一把手）｜价值主张（记得
   住→盯到闭环）｜验收词（门禁绿→打动与真用）｜范围（通用
   →小众判断工作 + AI 擅长过滤器）。桌面主对象/首开迁移仍是形态候选，不凭未定形态定罪旧资产。
2. **历史处置先例**：总体思路 §六的 09-25 版处置表（对旧资产的逐项裁决）——本卡要做的是
   **处置表 v2**（对 10-05 定位的再裁决）；死路回退与 note 纪律（根 AGENTS 规则 6）；
   rejected/ 存负知识。
3. **纪律资产的二重性**：治理/门禁/评测既是"自指闭环"的燃料，也是"打动 CFO"的可信度资产
   （261005 第 7 轮）——**打扫 ≠ 砍纪律，是重新归位**（有些从产品面退到开发者面，有些退役，
   有些升格）。

### 未决（候选清单——均为假设，未定罪；逐个过"三问"）

- **机制面**：self-reflection / home-curation / research 房间的学习回路件（燃料≈0）；
  skill-proposals 提案流程；memory-hygiene 的归属（dev 工具还是产品面？）。
- **门禁面**：34 道 verify 逐条三问——哪些只服务过程、不服务产品与说服。
- **数据面**：dev home 试车场数据、trial home 残留、探针会话残留（261001 卡曾多轮清理）。
- **文档面**：docs/notes 链上指向已死方向的段落（语义漂移审计技能的用武之地）。
- **演示面**：harness 打扫的产品定义——管理层打开时看不到任何开发内脏（与 261001 卡
  残留清单、上游候选台账衔接）。

### SDLC 探索问题（要"探索出来"的流程长什么样）

1. 证据阶梯重排：评测分 / 真用摩擦 / 演示读数——新定位下谁优先、怎么合流？
2. 切片节奏：行为面 / 界面面 / 内容面 / 打扫面分别的节奏与次序（261005 第 17 轮：行为面
   先于界面面）。
3. **打扫的程序**：三问判据 → 定罪 → note（输掉方案留档）→ 处置（删 / 藏进开发者面 /
   升格）——处置表 v2 的列怎么设。
4. "演示驱动"与"真用驱动"两条线的合流点与冲突裁决（261005 第 8 轮：一把手优先）。
5. 门禁预算制：新定位下新增门禁的门槛（"曾坏过或会静默坏"判据是否仍够用）与**既有门禁
   的退役条件**（此前只有"新增要理由"，没有"退役要程序"）。

## 候选与取舍

- **审计判据（三问）**：①这个资产服务两目的之一吗（真用 / 打动）？②服务一把手定位吗？
  ③删了会失去什么证据或能力？——三问全否 = 丢弃候选（note 留档）；①②否而③是 = 藏进
  开发者面（降可见性，不删）；①是 = 留守并按新判据重排优先级。
- **输掉的方案（预告）**：一次性大扫除（破坏性大、误杀可信度资产、不可回退）输给逐切片
  处置；只加不减（流程债复利）输给显式退役程序；按"代码年龄"砍（年龄≠无意义）输给三问。

## 毕业门

- **触发与范围**：资料层核查随本轮用户请求已开展；产品资产只读审计可在有界范围授权后推进，不要求等完整实验/真人周期。其产出是三问证据与处置候选，不自动毕业。
- **该做**：每项处置明确 owner、现行消费者、回归保护、删除损失、替代方案与回退办法，才形成具体 proposed；重大/破坏性处置获得相应授权后执行，阶段内技术判断不逐动作请示。
- **门禁退役**：先列原防护风险、曾坏过/静默坏证据、现行消费者与替代防护；旧反例在替代防护下红绿成立才判退役，不能因为门禁不直接改善演示就删除。
- **放弃**：不砍可信度资产（评测/治理语义/出处纪律/model-visible means logged）——它们是
  打动管理层的一部分；一切丢弃必留 note（负知识），vendor 永不改。
