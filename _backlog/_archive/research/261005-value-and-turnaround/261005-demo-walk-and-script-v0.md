# 十分钟走查记录与演示脚本候选 v0（督办主线）

> 喂 [定位卡](../../settled_issues/261005-open-value-deficit.md) 与 [自洽卡](../../settled_issues/261005-turnaround-coherence.md)。性质：供攻击的候选脚本，不是实施授权，也不是现有能力清单。
> 原走查依赖 blank-first-open 快照、trial 产物与 delegated naive-CEO 读数。代理评价不是实际管理层反应，trial 账面不是本人两周经营证据。本轮校准脚本的状态/数据边界，未重新运行浏览器或真人演示。

## 一、历史走查：已记录观察与解释

| 时刻 | 原记录所见 | 解释/局限 |
|---|---|---|
| 0:00 | 中文 UI；hero/placeholder 仍有开发者文案、预览弹窗 | 首屏语言负担是代理读数，vendor 候选见上游材料，非当前每个安装必现 |
| 0:30 | 欢迎语与经营问题例句 | 已有入口提示，不证明真人知道首件要做什么 |
| 1:00–3:00 | 回合等待、工具行、路径、思考预览、遥测 | 等待与技术信息竞争注意力；运行耗时随任务/模型变，不承诺固定分钟 |
| 3:00 | 拆解、分歧、可证伪假设、行动表 | 原 naive-CEO 判“军师级”，只是输出自评，不证明管理价值已成立 |
| 4:30–6:00 | 打开/刷新桌面，决策卡、行动表、缺数 | 可以展示产物，但要披露来源、生成时间和是否真实经营 |
| 8:00 | 知识待审/来源/excerpt | 审批当前走模型提示回退，不能称当场直调内联审批，见 [技术审计](261005-turnaround-evidence-audit.md) |
| 9:30 | 记忆室 | 机制可见，不等于 P2 已有真实同类决定证据 |

推论：可以先给一个可核成品，再解释来历，降低等待窗口。不是“所有演示必须桌面倒装”或首屏迁移已定；入口效果仍待实际受众。

## 二、目标脚本：状态逐段分开

框架来自 [演示叙事研究](../../../research/261005-ceo-value-positioning/261005-exec-demo-narratives.md)：结果先行、少量清晰动作、人审/出处、具体下一步。营销演示、董事会汇报与实际上手不同；Atlassian +90% 是转引，不作本产品采纳因果依据，CFO 审计页是主线的支撑不是第二主线。

| 段 | 候选动作 | 当前状态 / 展示条件 |
|---|---|---|
| 0:00–1:30 可核成品 | 打开一个决定的选项、跟进与缺数 | 桌面产物已有形态；“这是两周真实拍过的决定”只能有相应真实来源才说。否则明确“示例”，不伪造真账面 |
| 1:30–3:00 回访一件事 | 展示到期、阻塞与一次提醒/反馈 | 目标路径，业务主动提醒未验证。不能说“它今早提醒过我/自动催收中”而无投递日志 |
| 3:00–6:00 拍新事 | 给真实输入、看备选、本人选定、记录决定 | 现有拆解/桌面刷新可作为待复验路径；即时内联审批尚未贯通。不把模型提示回退隐藏成直接 RPC；live 或录像各自标明 |
| 6:00–8:00 可信依据 | 打开来源、状态、实际审批/执行记录 | 字段/curate 已有，审计与 verified 契约需补。只说已证实的存储/端点边界，不说“数据不出域”；40题有自指/机器评分，不当真人价值验证 |
| 8:00–9:30 错误与修正 | 展示一条真实反馈如何处理 | 反馈管线不等于每条学习都可证明。找不到来源时承认未知，不以演示排练代替 P2 |
| 9:30–10:00 下一步 | 请对方带一件可脱敏决定试用并给观察 | 候选受众动作；不承诺次日自动解决或两周必见收益 |

## 三、受控路径与隐私

- 演示前核对来源、采集时间、真实/示例标签；真实经营内容、截图、导出先匿名化与白名单确认。
- 录像/缓存/预生成坦白标注；现场失败有可核静态成品兜底，不以预录冒充实时执行，不 live 改配置。
- 模型 API/OV embedding/VLM 可能远端；本地 storage 不是端到端不出域保证，按实际允许边界选择输入。
- coding-agent 对照用相同经营任务、输入和评价；官网叙事/界面噪声只能解释入口差异，不证明我们的结果优于它。

## 四、仍待攻击的问题

1. 原型先用 [公开案例/标注模拟](261005-prototype-cases-and-interview-method.md) 检验“记录→跟进→回访”的状态与缺数处理；有真实决定时再检验实际采用/价值，不把拿到真人数据当开工前置。
2. 入口失效时是否可用低成本原型先检验，避免再次等真用/等周期？
3. 真人受众愿意带自己的脱敏问题、再次打开或要求试用，哪 1–2 个动作作判据？由实际言行判断，不由代理打分。
4. [却步点研究](261005-coding-agent-exec-barrier.md) 已完成，但公开叙事不证明用户行为；是否需要对照帧仍候选，不再等“在途研究”。
5. 种子/口径质量与 OKF 结构分别评估；四格不能独自回答“该厚哪页”，真实缺口和等内容消融各有职责。
