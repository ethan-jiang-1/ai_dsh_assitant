# _archive · 已经离开活跃区

默认不要读。点名才打开。前面的 `_` 就是这个意思。

| 目录 | 放什么 |
|---|---|
| [`closed/`](closed/README.md) | 推敲卡已经有结论。结论写在卡的状态行 |
| [`bugs/`](bugs/README.md) | 修完的缺陷。下一个号在 [`../bugs/README.md`](../bugs/README.md) |
| [`suspended/`](suspended/README.md) | 还没有结论，被明确搁置 |
| [`research/`](research/README.md) | 跟最后一张活卡一起离开的调研 |

搬进来用 `git mv`。文件名不变，正文不改。状态行上的去向可以在它指向的笔记挪走时改掉。

缺陷的下一个号在 [`../bugs/README.md`](../bugs/README.md)。
