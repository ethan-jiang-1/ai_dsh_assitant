## 原型研究：只选现在可由 agent 完成的事

用户本轮纠正：目前很难获得真实经营决定及回访，研究先做 agent 能完成的；可以搜公开案例、设计访谈框架，让以后收集的信息逐步改进助手。原型成熟不等真人招募/输入，不把缺真人数据当研发阻塞。

| 当前可做 | 有界产物 / 停止线 | 影响的判断 |
|---|---|---|
| **公开决定/复盘案例** | [来源线索与模拟设计](../reference/positioning/261005-prototype-cases-and-interview-method.md)：已定位官方入口，正文取回受限，两个具体已核案例尚未交付。不以空字段冒充重放；可先用标注模拟检查输入/追问/状态，来源恢复再补截止时点与动作/结果 | 输入/追问/决定记录/跟进信号是否足够明确，形成可离线验证的最小场景；具体案例证据仍未齐 |
| **访谈与能力积累框架** | [访谈学习框架](../reference/positioning/261005-interview-learning-framework.md)：短事件访谈、原始/推论分离、memory/research/knowledge/skill路由、条件例外、变更与验证卡。不联系真人，不把模拟回答当访谈 | 框架本轮可用；运行时接入另作有界方案，资料增长不等能力增益 |
| **技术契约/数据边界** | 已有审计基础上自主读源码/配置，明确实际车道、可测试方案和允许端点；活进程未知就限定结论，无需为原型等用户给经营数据 | 不承诺审批闭环/全链路本地；需要活体证据的主张仍留未验 |
| **可辨识仪器设计** | 隔离/哨兵/配对manifest、readiness、评分、成本/停止线；可测试设计先毕业，实施与正式批次各有验收 | 效果未知可由成熟实验去验证，不能先实施再授权 |
| **条件引用核查** | 仅在拟对外讲独有/收益数字时查对应原始资料；拿不到撤回表述 | 不继续泛CEO/竞品综述 |

真实访谈、本人同类决定和回访以后获得时再提升证据等级，**不属于当前待用户交材料的队列**。没有这类数据，仍可验证原型机制/场景逻辑和条件变化后的行为，不能宣布经营价值、个性化或采纳已验证。公开案例用于通用方法，不能塞成用户公司的事实。

|---|---|---|
| **0 方向收敛** | 一把手总助、AI分工边界、公开/模拟原型证据等级、既定技术偏好；旧真用方案退出活跃队列 | 当前方向已确认；主对象/首开具体形态仍可通过原型选择，不要求现在定死全部界面 |

### 卫生的最小边界

先清活跃读面和会进入运行上下文的内容，再处置没有职责/消费者的实现。历史反证归既定生命周期，源码无消费者且替代防护清楚才删除；只靠年龄、0次计数或“不直接改善演示”不能定罪。日用home/vendor不在清扫面；开发残留与仓库资产分开。卫生审计不依赖完整四格/真人数据；UX草图可并行准备，新增产品落地在卫生出口后开始。

### UX如何主导技术选择

先写具体用户动作与可见结果，再列最低状态/工具/数据需求，最后选承载。UX不只排版，也包括首件能做什么、等待/失败的反馈、确认与纠正、回访负担；不能把“先行为后界面”变成无限技术前置。内联审批、Conversation View桌面、intake/样板间等按路径原型选择，不因技术slot存在就定为主对象。

技术偏好归 [DSH原生定调](../reference/tech-exploration/261005-dsh-native-first-tech-keynote.md)：`Agent = Model + Harness`；OKF承载语义知识/生命周期，VK承载情景记忆；组合 → 既有缝 → 有证据的自建。一个UX动作要说明采用的DSH载体、尚缺什么、失败/关闭/日志边界；不为“用足插件”强行多装能力。沿用四工具/四房间，runtime技能与开发技能分开，Web/Desktop、不做IM；技术方向已确认，效果和活体数据边界分别验证。

最小跟进只读实际提供的本地到期行动、待拍决定和缺数；公开/模拟数据明确标记。桌面是状态投影，稳定id/版本/owner/状态转换/完成证据支持它；提醒必须有静默、延期、去重/合并和预算，缺新信息不催、重启不重复、无证据不编完成。没有外部执行证据只称本地决定跟进。

P2的“贴合本人”结论以后需本人案例检验；当前可用公开/模拟病例验证记忆与条件变式，真人输入和30天周期都不是原型研发前置。

## 毕业门：按具体问题毕业，不整卡搬总路线

问题/方案/验收齐全是最低形态；还必须说清承重未决、备选与失败、owner/依赖和可回退边界。未知效果可由一个成熟实验去验证，不能把未知契约隐藏成“实现时再定”。

| 潜在切片 | 毕业前需闭合 | 暂不毕业的理由 |
|---|---|---|
| 审批契约/失败恢复 | 确定实际车道、本人显式确认、verified 含义、身份/页归属、成功/失败/审计/重试语义与可测试方案 | 缺契约选择与运行路径证据 |
| OKF/VK 仪器与实验 | 仪器提案先闭合 manifest、等内容控制、隔离/哨兵负测、readiness、金标准/盲评、成本停止线与可测试实现方案；正式批次另依赖仪器运行验收 | 静态风险已查清，可测试方案尚未闭合；不以隔离器先实现为其实施提案的前置 |
| 最小督办原型 | 公开/模拟场景及缺数边界、稳定id/owner/状态转换、输入/投递预算、重启/重复/反馈验收与DSH承载；不编造真实执行 | 可测试状态契约待闭合，真实经营输入不是实施提案前置 |
| 访谈到能力积累 | 输入/来源定位、四房间路由、条件例外、学习候选的前后/未见病例验证、版本/启用/撤回与批准范围 | 框架已有，运行时受控链路未设计完；不把文件落地当效果已验证 |
| 形态迁移 | 对应行为与入口证据、旧会话回路、示例/真实/来源/审批/撤销边界 | 主对象/首开候选尚未检验，不等完整四格才能做原型 |
| SDLC处置 | 三问逐资产证据、消费者、回归/替代防护、损失、回退锚点和处置范围 | 已定旧任务/资料项先处理；产品行为/重要防护的退役需逐项闭合证据，不泛称卫生即删除 |

本轮已交资料治理、旧主轴退役、公开案例/访谈框架与总体策动材料；卫生先行的审计和常规可回退处置按用户范围推进。产品实现、重大契约/重要防护删除、运行数据清扫与外部递交不因总体计划自动获授权；有界切片成熟后按现行流程实施，阶段内技术取舍自主。此卡仍活跃，具体事项尚未毕业；计划/资料完成不等于产品转向完成。

## 输掉的方案与停止条件

- 同步三份活计划、总路线直接进 proposed：第二事实家/未决冒充成熟，输给 owner 分工和单项毕业。
- 为了合拍改证据、把代理当真人或留痕当正确：无法反驳，输给来源/推论/状态分离。
- 扩大泛研究、等全实验/周期才检验入口：重建双向等待，输给有界问题与并行探针。
- 一次性删除旧机制/门禁：可能损失可信度与回归，输给 SDLC 三问与逐资产证据。
- 隔离失败停止实验批次；提醒重复/误报超预算停止扩大投递；真实账面/受众不足只冻结对应价值结论，不伪造数据或把其余工作全部挂起。
