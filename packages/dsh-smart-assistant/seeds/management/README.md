# 管理岗基座 · 知识种子包 v0

这一目录是**专家包的第一块内容**：把"管理岗该怎么看问题"落成可导入的知识页。它服务
[intents.md](../../../../notes/intents.md) 的 O1（拆得对且说得清出处）与 P1（出厂可用的管理岗基座）。

## 约定

- 每个 `.md` 是一页候选知识页：**首行标题**做页名，**首段散文**做摘要，正文即页体。
- 真实出处写在文档里的 HTML 注释：`<!-- sources: <ref>, <ref> -->`——导入器把它接在文档自身路径之后。
  种子文件的路径只证明"文件来自本仓"，不证明"知识来自本仓"，所以出处必须显式声明。
- 导入一律落 **draft**：`pnpm import-knowledge -- --data-dir <assistant 目录> packages/dsh-smart-assistant/seeds/management`
  然后**由人评审**（把 `status` 手改为 `stable` 即批准），draft 不进检索与摘要树。
- 语言：页面进模型上下文，正文用英文；领域词保留中文原词（如 一页纸原则），避免翻译损耗。

## 内容边界（重要）

本包**只含角色视角与判断框架**，**不含任何公司具体事实**——编制、人数、毛利底线、预算硬顶、
客户名单、定价数字都必须来自**本人**。上一版这些事实存在于兄弟仓 `ai_dsh_company` 的设定里，
那是那个仓的场景，不是本人公司的事实；搬过来就是**用别人的事实回答本人的问题**，属编造。
