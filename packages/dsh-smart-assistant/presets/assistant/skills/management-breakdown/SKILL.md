# Management breakdown

A problem the principal cannot act on has not been broken down yet. Break it before advising.

## The four layers, in order

1. **Observed facts.** What is actually seen, each with a number and a period where possible.
   Facts need provenance — a page, a figure, a person — or they are assumptions wearing facts' clothes.
   Mark every unproven item as an assumption here, not in layer 2.
2. **Cause hypotheses.** Two to five candidate causes, each **testable** and each naming
   the data that would confirm or kill it. One cause per line; a cause that cannot be tested is a
   guess, and guesses do not go into plans.
3. **Decision criteria.** What each lens demands — the chief executive's whole-outcome
   view, finance's cash/margin/compliance view, sales' customer-reality view (the lens pages in
   your knowledge room). Where lenses disagree, **keep the disagreement visible**; flattening it at
   merge time destroys exactly the information the decision needs.
4. **Actions.** Only after 1–3. Each action gets an owner, a timing, a metric, and a stop
   condition (see the action-plan skill). The stop condition is not optional and not implied by
   the metric: label it explicitly on every action — including information-gathering steps, where
   it is "what result makes this step pointless or reverses the plan". An action row without a
   labeled stop condition is the layer most often quietly dropped; the principal cannot commit to
   a step whose exit they cannot see.

## Rules that keep it honest

- **Facts vs hypotheses vs judgements** — label which is which. A number without provenance is an
  assumption; a preference stated as a fact is a lie.
- **One page.** If the breakdown does not fit on one page it is not finished; compression is the work.
- **Conclusions first, then the layers.** The principal reads the answer, then checks the reasoning.
- **Do not invent company facts.** Headcount, margins, customer names, thresholds — those come from
  the principal or the knowledge room, never from you. If a needed fact is missing, say so and name
  where it would come from.
- **Preserve the principal's judgement standards.** When working with this principal's own criteria
  (from past sessions), cite which session taught you the criterion.

## Output shape

```
Conclusion — one paragraph, first
1. Observed — fact / fact / assumption (why)
2. Hypotheses — H1 (test: …) / H2 (test: …)
3. Criteria — CEO: … / CFO: … / Sales: … (disagreements kept)
4. Actions — each: owner / timing / metric / stop condition
Unsettled & missing data — what could not be settled, and where that data lives
```
